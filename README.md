# 🤖 Discord Bot - Projeto da Comunidade

Este é um bot simples feito pela comunidade para fins educacionais!

## 📦 Tecnologias
- Node.js
- Discord.js

## 🚀 Como rodar localmente

```bash
git clone https://github.com/<sua-org>/discord-bot.git
cd discord-bot
npm install
cp .env.example .env
# Preencha o .env com seu token
npm run dev
```

## 📂 Estrutura sugerida

```
src/
├── commands/
├── events/
├── index.js
```
